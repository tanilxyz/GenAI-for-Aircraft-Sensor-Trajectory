## Synthetic Sensor Trajectory Generation Using Generative Models for Aircraft Predictive Maintenance

This project explores the use of Generative AI for aircraft predictive maintenance using the NASA C-MAPSS FD001 dataset. A Variational Autoencoder (VAE) is trained to generate synthetic aircraft engine sensor trajectories, which are then used to augment the original dataset.

An LSTM-based Remaining Useful Life (RUL) prediction model is trained on both real and augmented datasets to evaluate the impact of synthetic data on predictive maintenance performance.

Key Features:\
NASA C-MAPSS FD001 dataset\
VAE-based synthetic sensor trajectory generation\
LSTM-based RUL prediction\
Comparison of real vs. augmented training data\
Evaluation using MAE, RMSE, and R² metrics\
Tech Stack\
Python\
TensorFlow / Keras\
NumPy\
Pandas\
Scikit-Learn\
Matplotlib

Objective\
To investigate whether synthetic sensor trajectories generated by generative models can improve aircraft engine Remaining Useful Life prediction and support predictive maintenance applications.
